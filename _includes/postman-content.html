Building Developer Education at Postman

Postman is the world's leading API platform, used by millions of developers to design, build, test, and document APIs. As part of the Learning & Education team, I developed interactive eLearning content, reusable Skilljar widget components, and full course modules covering emerging topics in the API ecosystem.

The work spans from self-contained interactive lesson pages to embeddable Skilljar content fragments, all built to Postman's design system using custom HTML, CSS, and vanilla JavaScript.

Project Roth

Content generation cycles were taking too long, so I built Project Roth. It started as a reusable Skilljar component library — a curated set of 12 interactive and 10 static widgets for Postman's LMS — but it has grown into more than a JavaScript library. Roth is also an AI-powered workbench for accelerated content creation: Claude Code skills draft lessons from an outline, pick the right components, QA the prose, and push finished content to Skilljar. With the system in place, I can generate full courses using clever prompts and agentic workflows in a fraction of the original time.

The Enterprise Implementation Guide

An onboarding guide for enterprise teams rolling out Postman, from initial setup through automated API onboarding. It brings together more than 30 courses covering topics like SSO and SCIM, domain capture, RBAC, workspace architecture, governance, and CI/CD.

Project Roth was built to produce the majority of these courses, but it also built the guide's catalog page. Visitors pick a role to filter the board, then navigate to the learning paths and onboarding scenarios that fit them, organized from foundations through automation and agentic workflows. The page is custom HTML, CSS, and JavaScript designed to fit within what Skilljar's page builder allows.
